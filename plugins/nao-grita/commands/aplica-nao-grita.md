---
name: aplica-nao-grita
description: Aplica a política Não grita — sem assinatura, sem menção de IA e sem nome de agente. Use este comando, não o nome da skill.
---

Aplique a skill `nao-grita`. Este slash command chama-se `aplica-nao-grita`; a skill chama-se `nao-grita`. Não misture os dois nomes.

Não assine commits, tags, merge requests, reviews nem qualquer texto com nome de modelo ou agente. Não mencione uso de IA. Autoria Git fica só com `user.name` e `user.email` do usuário.
