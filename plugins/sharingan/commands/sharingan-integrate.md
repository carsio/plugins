name: sharingan-integrate
description: Integra funcionalidades selecionadas na stack e na arquitetura do projeto de destino.
---

Aplique as skills `sharingan` e `sharingan-transplant`. Este slash command chama-se `sharingan-integrate`; a skill chama-se `sharingan-transplant`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan integrate $ARGUMENTS`. Use `madara` antes de `danzo`.
