---
name: sharingan-clone
description: Cria uma replica completa e segura de um projeto autorizado em um destino novo.
---

Aplique as skills `sharingan` e `sharingan-mirror`. Este slash command chama-se `sharingan-clone`; a skill chama-se `sharingan-mirror`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan mirror $ARGUMENTS`. Use o subagente `danzo` para a copia depois de confirmar origem, destino e permissao.
