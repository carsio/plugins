Aplique as skills `sharingan` e `sharingan-validate`. Este slash command chama-se `sharingan-check`; a skill chama-se `sharingan-validate`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan validate $ARGUMENTS`. Use o subagente `itachi` para a parte somente leitura.
