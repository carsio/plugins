description: Cataloga as funcionalidades de um projeto autorizado, com IDs e mapa de dependencias.
---

Aplique as skills `sharingan` e `sharingan-catalog`. Este slash command chama-se `sharingan-list`; a skill chama-se `sharingan-catalog`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan list $ARGUMENTS`. Delegue a varredura ao subagente `kakashi` quando o projeto for grande. Nao altere codigo.
