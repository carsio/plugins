---
name: sharingan-help
description: Mostra a ajuda do Sharingan ou executa um comando $sharingan (list, inspect, mirror, integrate, brand, validate, audit).
---

Aplique a skill `sharingan`. Este slash command chama-se `sharingan-help`; a skill orquestradora chama-se `sharingan`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan $ARGUMENTS`. Sem argumentos, execute `$sharingan help` e mostre a tabela de comandos.
