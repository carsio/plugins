---
name: sharingan-rebrand
description: Altera nome, marca, cores, textos, imagens, dominios e identificadores de uma replica ou integracao.
---

Aplique as skills `sharingan` e `sharingan-brand`. Este slash command chama-se `sharingan-rebrand`; a skill chama-se `sharingan-brand`. Nao misture os dois nomes.

Interprete os argumentos como `$sharingan brand $ARGUMENTS`. Use o subagente `obito` para montar o mapa antes de editar.
